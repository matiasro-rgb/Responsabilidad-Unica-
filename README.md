# Responsabilidad-Unica-
[Responsabilidad Unica.zip](https://github.com/user-attachments/files/34052601/Responsabilidad.Unica.zip)
Este principio dice que cada clase debe tener una responsabilidad específica, en este código se utilizan dos clases Libro y Guardar, la clase Libro se encarga de almacenar la información del libro, como el título y el autor. Por otro lado, la clase Guardar se encarga de mostrar el mensaje de que se está guardando el libro, de esta manera, cada clase tiene una función diferente y no se juntan todas las responsabilidades en una sola clase.
